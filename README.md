# TankerPlan

Akaryakıt tankeri göz bazlı yükleme planlama prototipi.

## Kurulum

```bash
npm install
npx expo start
```

İlk örnek katalog: Aytemiz dizel ürünleri Optimum ve Motorin; benzin ürünü yalnızca 95 Oktan Kurşunsuz Benzin.

Bu uygulama planlama prototipidir. Gerçek yükleme öncesinde ürün uyumluluğu, tanker bölme yapısı, ağırlık limitleri, dolum prosedürleri ve güvenlik kontrolleri yetkili kişilerce ayrıca doğrulanmalıdır.
